Как подключить «WB Аналитику» к своему кабинету

Приложение показывает прибыль, выкуп, брак, логистику, ДРР (в том числе по рекламным кампаниям), остатки и налог по вашему кабинету Wildberries. Займёт 20–25 минут. Нужен компьютер (для таблицы) и телефон.

Данные хранятся только в вашей Google Таблице. Ключ WB — только в вашем скрипте. Автор приложения ваши данные не видит: приложение на телефоне обращается напрямую к вашей таблице.

1Ключ API в кабинете WB

  1. Кабинет продавца → Профиль → Настройки → Доступ к API → «Создать новый токен».
  2. Тип: Персональный.
  3. Категории: Статистика, Финансы, Продвижение, Аналитика, Контент. Галочка «Только на чтение».
  4. «Создать» → скопируйте ключ целиком и сохраните в заметку (WB показывает его один раз).

2Таблица со скриптом (на компьютере)

  1. Откройте sheets.new — создастся пустая Google Таблица. Назовите её «WB Аналитика».
  2. Меню Расширения → Apps Script. Удалите весь текст в окне.
  3. Скопируйте код скрипта кнопкой ниже и вставьте в окно. Нажмите значок дискеты «Сохранить».
    Открыть код
  4. Вернитесь на вкладку таблицы и обновите страницу (F5). Справа от «Справки» появится меню «WB Аналитика».
  5. «WB Аналитика» → «1. Ввести ключ WB». Google попросит разрешение: «Предоставить доступ» → ваш аккаунт → «Дополнительные настройки» → «Перейти на страницу проекта (небезопасно)» → «Разрешить».
    Предупреждение «Google не проверил приложение» — обычное для своих скриптов. Скрипт работает только в вашей таблице.
  6. Снова «1. Ввести ключ WB» → вставьте ключ из шага 1 → ОК.
  7. «WB Аналитика» → «2. Загрузить историю (90 дней)». Если в конце написано «Загружено не всё» — нажмите ещё раз, пока не будет «Готово».

3Открыть доступ для приложения

  1. В окне Apps Script: Начать развертывание → Новое развертывание.
  2. Шестерёнка рядом с «Выберите тип» → Веб-приложение.
  3. «Запуск от имени»: Я. «У кого есть доступ»: Все. → «Развернуть».
  4. Скопируйте URL веб-приложения — он вида https://script.google.com/macros/s/…/exec.
  5. В таблице: «WB Аналитика» → «Показать ключ доступа для приложения» — перепишите ключ вида xxxxx-xxxxx-xxxxx.

Отправьте себе адрес и ключ (например, в «Избранное» Telegram) — на телефоне их удобно скопировать.

4Приложение на телефоне

  1. Откройте в Chrome: happybeetlevova-ux.github.io/wb/
  2. «⋮» → «Установить приложение» (или «Добавить на главный экран»). На iPhone в Safari: «Поделиться» → «На экран Домой».
  3. Откройте приложение со значка → вкладка «Ещё» → вставьте адрес и ключ доступа → «Проверить и сохранить».
  4. Там же, в «Ещё», укажите свою ставку налога (по умолчанию УСН «доходы» 7%) и закуп по товарам — без закупа прибыль будет завышена.

Дальше всё обновляется само: заказы и остатки — каждый час, отчёты WB и реклама — каждую ночь.

Если что-то не так

«В ключе WB нет категории …»
Создайте новый ключ с категориями из шага 1 и введите через «1. Ввести ключ WB».
«Метод работает только с ключом типа Персональный»
Ключ создан как «Базовый» — создайте «Персональный».
«Ключ доступа не подходит»
Скопируйте его заново: меню таблицы «Показать ключ доступа для приложения».
«Google ответил не данными»
При развертывании не выбрано «У кого есть доступ: Все», или скопирован адрес не того развертывания.
Выручка за последние дни «предварительная»
Это нормально: WB выкладывает отчёт о реализации с задержкой, до него цифры берутся из оперативной статистики.

Обновление скрипта

Когда выйдет новая версия: Apps Script → удалить старый код → вставить новый (кнопка выше) → «Сохранить» → Начать развертывание → Управление развертываниями → карандаш → Версия: «Новая версия» → «Развернуть». Адрес и ключ в приложении не меняются.
